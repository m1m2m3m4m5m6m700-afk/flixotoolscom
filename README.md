# Flixo Studio

Create a production-ready web application called Flixo.

Tech Stack:

- Next.js (App Router)

- React

- TypeScript

- Tailwind CSS

Requirements:

- Build a beautiful premium landing page.

- Modern SaaS design.

- Dark and Light mode.

- Fully responsive.

- Smooth animations.

- Professional typography.

- Clean component architecture.

- Reusable components.

- Scalable folder structure.

Homepage Sections:

- Hero

- Search bar

- Featured Tools

- Categories

- Why Flixo

- Statistics

- FAQ

- Footer

Create only ONE working tool:

AI Translator

- Input textarea

- Output textarea

- Auto Detect language

- From language

- To language

- Swap languages

- Translate button

- Copy result

- Clear button

- Character counter

- Loading animation

- Error handling

- Beautiful empty state
